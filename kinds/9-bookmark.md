# kind 9: ブックマーク (bookmark)

- 保存: regular
- 現行API: `bookmark`, `bookmarks`
- 関連機能: [encryption](../features/encryption.md)

## 目的

自分だけが見られる「あとで読む」。現行どおり**非公開**。

## 構造

```json
{
  "kind": 9,
  "content": "m1:<base64>",     // 平文は [["e","<投稿id>"]]
  "tags": []
}
```

- 対象は暗号化した `content` の中だけに入れる。`e` タグを付けると公開されてしまうので付けない。
- 暗号化は**自分の鍵で自分宛て**([encryption](../features/encryption.md))。
- 取り消し = [kind 5](5-deletion.md)。

## リレーの検証

- `content` が `m1:` で始まる。タグは空(または `client` など無害なもの)。
- 読み出しは `authors:[認証済み自分]` のときだけ(ポリシー推奨。タグが無いので漏れても対象は分からないが、件数は分かる)。

## クライアントの扱い

- 一覧 = `{"kinds":[9],"authors":["<me>"],"limit":50}` → 復号 → `ids` で投稿を取得。
- 解除には**ブックマークイベントのid**が要るので、一覧取得時に「投稿id → ブックマークid」の対応表を持つ。
- 件数上限・保持期間はクライアントが決める(現行は表示50件)。

## 拡張ポイント

- 平文の中身は配列なので、フォルダ名・メモ(`["note","…"]`)を足せる。
