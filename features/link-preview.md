# 機能: リンクプレビュー(OGP)

- 使う: HTTP `GET /x/ogp`(イベントは使わない)
- 現行API: `ogp`(`ogp()` `http_get_safe()` `parse_ogp()`、`ogp_cache`)

## 考え方

クライアントが外部サイトを直接取りにいくと CORS で失敗し、閲覧者のIPも相手に知られる。そのため**リレー(または専用のプレビューサーバー)が代理で取得**する。署名イベントにする必要はない(誰が取っても同じ結果の、使い捨てのデータ)。

## API

```
GET /x/ogp?url=https%3A%2F%2Fexample.com%2Fpage
→ 200 { "ogp": { "title": "…", "desc": "…", "image": "https://…", "site": "example.com" } }
→ 200 { "ogp": null }          ← 取得できない・HTMLでない
```

| 項目 | 上限(現行) |
|---|---|
| `title` | 120文字 |
| `desc` | 200文字 |
| `site` | 60文字 |
| `image` | `http(s)://` の絶対URLのみ |

## 取得の安全策(必須。現行 `http_get_safe`)

SSRF(リレーを踏み台に内部ネットワークを叩かれる)を防ぐ:

- スキームは `http` / `https` のみ。`user:pass@` を含むURLは拒否。
- ホスト名を解決した**全IPが公開アドレス**であること(プライベート・予約済み範囲は拒否)。検証した IP に接続を**固定**(DNSリバインディング対策)。
- リダイレクトは最大4回、毎回同じ検査。
- 本文は最大 512KB、タイムアウトは短く、`Content-Type` が HTML のものだけ。
- 文字コードは UTF-8 / Shift_JIS / EUC-JP / ISO-8859-1 を判定して変換。
- URL は 480文字まで。

## キャッシュ・制限

- 成功は7日、失敗(`null`)は1時間キャッシュ(現行 `ogp_cache`)。
- 利用者単位のレート制限: ログイン(認証つき)40回/分、未ログイン(IP)15回/分。認証は [kind 20001](../kinds/20001-http-auth.md) の任意利用。

## クライアントの扱い

- 投稿本文の**最初のURL**だけプレビュー化し、画像付き投稿では出さない(現行と同様)。
- プレビューが取れなくても投稿は壊れない。

## 拡張ポイント

- 画像のプロキシ(`/x/ogp-image`)で閲覧者のIP漏れを防ぐ。
- oEmbed(動画・SNS埋め込み)対応。
