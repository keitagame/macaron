# 機能: メンション・ハッシュタグ・リンク

- 使う kind: [1](../kinds/1-post.md)
- 現行: 本文の `@handle` `#tag` を `api.php` が抽出し、`tags` 表と `notifs` に入れ、`app.js` の `rich()` がリンク化

## 書き方

分散では `@handle` が変わりうる・一意でないため、**参照は pubkey で書く**。

| 種類 | 本文の表記 | 付けるタグ |
|---|---|---|
| ユーザー | `macaron:pub:<64hex>` | `["p", <pubkey>]` |
| 投稿 | `macaron:note:<64hex>` | `["e", …]` や `["q", …]` は文脈で。単なる言及は `["r", "macaron:note:<id>"]` |
| ハッシュタグ | `#語` | `["t", "語"]`(小文字) |
| URL | `https://…` | (タグ不要。リンクプレビューは [link-preview](link-preview.md)) |

- クライアントの入力欄は、`@za` と打つと候補(フォロー中・最近のやりとり・ハンドル検索)を出し、選んだら `macaron:pub:…` に置換して `p` タグを足す。表示時はプロフィールの名前を引いて `@名前` と描く。
- **タグが正**(通知・検索の根拠)。本文の参照とタグが食い違ったらタグを優先。

## ハッシュタグ

- 正規表現は現行どおり: 行頭または空白の直後の `#` + `[\p{L}\p{N}_]{1,50}`。
- タグは Unicode 小文字化(`mb_strtolower` 相当)、重複は1つ。
- 検索 = `{"kinds":[1],"#t":["語"],"limit":60}`。

## メンションの上限・通知

- 通知対象は最大10人(現行)。超えた分は表示だけ。上限はリレーの `max_p_tags` ポリシーでも守る。
- 返信先・引用元の作者とメンション先が同じ人なら、`p` は1つだけ(現行の `$done`)。

## 拡張ポイント

- 本文中の位置情報(オフセット)が要るなら `["ref", <offset>, <len>, …]` を足す。今は不要。
